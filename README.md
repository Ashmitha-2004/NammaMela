🎭 NammaMela - Digital Theatre Booking and Management Android App

📌 Project Overview
NammaMela is an Android application for digital theatre booking and management.  
It allows users to browse theatre plays, view cast details, book seats, and interact through a fan wall system.

This project was developed as part of an internship to demonstrate Android development using Kotlin.

✨ Features
- ✔ User Login and Signup
- 🎬 Browse Theatre Plays
- 🎭 Cast and Crew Information
- 💺 Seat Booking System
- 🎟 Ticket Generation
- 💬 Fan Wall (User Comments)
- 🛠 Admin Panel for managing plays and cast
- 📱 Simple and user-friendly UI

🛠 Tech Stack
- Kotlin
- XML (UI Design)
- Android Studio
- Room Database

🚀 How to Run
1. Clone the repository  
   git clone https://github.com/Ashmitha-2004/NammaMela.git

2. Open Android Studio  
3. Click Open Project  
4. Select the inner project folder  
5. Wait for Gradle Sync  
6. Click Run ▶
